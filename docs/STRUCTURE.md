# Project Structure

Struktur folder utama project.

```text
.
├── backend
│   ├── config
│   ├── controllers
│   ├── middlewares
│   ├── models
│   ├── routes
│   └── types
├── frontend
│   ├── public
│   └── src
│       ├── assets
│       ├── components
│       │   ├── auth
│       │   ├── layout
│       │   ├── partials
│       │   └── ui
│       ├── hooks
│       ├── lib
│       │   └── stores
│       └── pages
└── docs
```

## Penjelasan Singkat
- `backend`: API server, auth logic, database integration.
- `frontend`: aplikasi client React.
- `docs`: dokumentasi pengembangan dan referensi teknis.
