# frontend/src/pages

Komponen halaman aplikasi.

## Isi
- `login.tsx` -> halaman login/register (guest layout).
- `dashboard.tsx` -> halaman dashboard setelah login.
- `user.tsx` -> halaman daftar pengguna.
- `about.tsx` -> halaman dokumentasi README in-app.
- `error.tsx` -> halaman error fallback.

## Mapping Route
- `/` -> `login.tsx`
- `/dashboard` -> `dashboard.tsx`
- `/users` -> `user.tsx`
- `/about` -> `about.tsx`
- `*` -> `error.tsx`
