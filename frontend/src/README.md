# frontend/src

Folder source code utama frontend.

## Entry Files
- `main.tsx` -> bootstrap React + konfigurasi global axios credentials.
- `App.tsx` -> deklarasi route aplikasi.
- `index.css` -> style global + Tailwind utilities.

## Subfolder
- `assets` -> image/icon source.
- `components` -> komponen UI, layout, dan auth guard.
- `hooks` -> custom React hook.
- `lib` -> utilitas dan state stores.
- `pages` -> komponen halaman per route.
