# frontend/src/components/partials

Komponen UI level fitur/halaman.

## Isi
- `authForm.tsx` -> form login/register.
- `aboutContent.tsx` -> konten README di halaman `/about`.
- `navbar.tsx` -> navigasi utama + logout.
- `welcome.tsx` -> container card header reusable.
- `welcomeCard.tsx` -> konten dashboard ringkas.
- `userList.tsx` -> tabel data user.
- `formCard.tsx` -> card wrapper form auth.
- `formField.tsx` -> input field umum.
- `passwordField.tsx` -> input password dengan toggle visibility.
- `submitButton.tsx` -> tombol submit form.
- `logo.tsx` -> komponen logo teks/icon.
